The Global Geopolitical Events (GGE) Database measures bilateral geopolitical alignment using historical political events identified, classified, and scored with large language models.

<dl class="data-facts">
  <div><dt>193 countries</dt><dd>UN member states</dd></div>
  <div><dt>1950–2024</dt><dd>Annual coverage</dd></div>
  <div><dt>18,528 pairs</dt><dd>Bilateral relationships</dd></div>
</dl>

## Available data

The current release contains bilateral geopolitical alignment scores for all 18,528 country pairs over 1950–2024, a panel of 1,389,600 country-pair-year observations. The scores draw on an underlying database of 833,485 political events.

- [Download alignment scores and documentation](https://github.com/tianyufan-econ/global-geopolitics#this-release)
- [View the GitHub repository](https://github.com/tianyufan-econ/global-geopolitics)

<p class="release-note">Version 1.0, June 2026. Alignment scores are available as a compressed CSV. Complete event-level records are forthcoming.</p>
